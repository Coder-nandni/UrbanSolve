# 🌆 UrbanSolve – City Problem Management System

## 📌 Problem Statement
Cities face multiple issues like garbage, water leakage, street dogs, and electricity problems. Citizens often don't have a proper platform to report these issues efficiently.

## 💡 Solution
UrbanSolve is a web-based platform that allows users to:
- Report issues with images 📸
- Add live location 📍
- Track issue status (Pending, In Progress, Resolved)
- Get faster response from authorities

## 🚀 Features
- User Registration & Login
- Issue Reporting with Image Upload
- Live Map Integration (Latitude & Longitude)
- Ticket Generation (UP-XXXXX)
- Admin Dashboard with Analytics
- Status Tracking System
- Category & Priority Management

## 🛠️ Tech Stack
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Backend: PHP
- Database: MySQL
- Map: OpenStreetMap + Leaflet

## 📊 Project Workflow
1. User logs in
2. Reports issue with image & location
3. System generates ticket
4. Admin reviews and updates status
5. User tracks progress
